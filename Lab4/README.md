# ARTI402 – Lab 4: Recurrent Networks

Implement RNN and LSTM cells using NumPy, count recurrent parameters, and compare memory retention across different sequence lengths.

## Requirements
- Python 3
- NumPy
- Matplotlib
- Jupyter Notebook

## Run
Keep `arti402_figures.py` in the same folder as the notebook, then run all cells in order.

## Results
The LSTM retains information over longer sequences than the plain RNN. A higher forget-gate bias improves memory retention in this experiment.
