# ARTI402 – Lab 5: Optimizers

Implement backpropagation, mini-batches, SGD, Momentum, RMSProp, and Adam from scratch using NumPy. Compare their performance on a spiral classification dataset and explore learning-rate effects.

## Requirements
Python 3, NumPy, Matplotlib, and Jupyter Notebook.

## Run
Keep the updated `arti402_figures.py` beside the notebook and run all cells in order.

## Results
Adam achieved approximately 96.7% training accuracy and 82% test accuracy. Learning-rate selection significantly affected performance.
